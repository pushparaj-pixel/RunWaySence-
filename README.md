# RunwaySense

Intelligent runway safety predictor.

**Live demo:** https://pushparaj-pixel.github.io/RunWaySence-/runwaysense-1.html

## What it does
- Estimates landing distance from aircraft weight, runway length, wind, temperature, pressure and surface condition
- Runs 4,000 Monte Carlo landings to give an overrun probability
- Checks crosswind and tailwind limits and hydroplaning speed
- Shows what is costing runway and what to do about it
- Exports a PDF report

## Tech
HTML, CSS, JavaScript, jsPDF. Single file, no install.

## Note
Educational model with simplified physics. Not for flight planning or operational decisions.
